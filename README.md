# Dotadle: угадай героя Dota 2 (сайт + Discord Activity)

Один проект работает двумя способами:
- **как сайт** с входом через Google или Discord;
- **как Discord Activity**: игра запускается прямо в голосовом канале, вход происходит автоматически.

## Что внутри

**Режимы**
- 🧩 **Классика.** Ежедневный герой: вводишь героев, и игра подсвечивает атрибут, тип атаки, роли, ноги, скорость и дальность. Очки: 10 за первую попытку, дальше -1 за каждую (минимум 1). Первый угадавший за день получает +2.
- 🖼️ **Портрет из символов.** Ежедневный герой, 6 попыток. С каждой ошибкой портрет становится чётче, а после 3, 4 и 5 ошибок появляются подсказки. Очки: 6 за первую попытку, дальше -1 за каждую.
- ⚡ **Гонка.** Все в комнате угадывают одного героя на скорость (классика или портрет). Места приносят +5, +3 и +2 очка, остальные угадавшие получают +1. В Discord комната = голосовой канал. На сайте комната создаётся по коду или ссылке. Очки начисляются, только если в раунде было 2 игрока или больше.
- ♾️ **Практика** (для саппортеров): бесконечный режим и архив прошлых дней, без очков.

**Рейтинги:** «Сегодня», «Сезон» (календарный месяц) и «Всё время», общий и по лигам.
**Лиги:** у каждого Discord-сервера лига создаётся автоматически. Свою лигу для друзей можно создать на сайте и раздать код.
**Аватарки:** у каждого игрока свой герой-аватар, его можно сменить в профиле. Поиск героев работает и по-русски («пудж», «войд», «кристалка»).

**Монетизация без рекламы**
- ⭐ **Саппортер** (донат): значок, цветной ник, 4 темы, практика, личная статистика, «Зал славы».
- 🏆 **Лига+** (для сервера или лиги): сезоны лиги с историей и турниры.
- 🤝 **Спонсоры:** у турнира может быть спонсор со ссылкой и призом, он показывается только на странице турнира.

Пока `PAYWALL=off` (так стоит по умолчанию), все функции открыты всем, можно спокойно тестировать с друзьями.
Значок ⭐ при этом показывается только тем, кто действительно активировал код саппортера.

## Запуск: шаг за шагом

### 1. Залей код на GitHub
Создай репозиторий на github.com и загрузи туда содержимое папки (кроме `node_modules` и `.next`).

### 2. Создай проект на Vercel
vercel.com → **Add New → Project** → выбери репозиторий → **Deploy**. Запомни адрес, например `https://dotadle-xxx.vercel.app`.

### 3. Подключи базу
В проекте на Vercel: **Storage → Create → Upstash for Redis** → бесплатный план → **Connect to project**.
Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.

### 4. Создай приложение в Discord
1. Открой discord.com/developers/applications → **New Application** (назови, например, Dotadle).
2. **OAuth2**: скопируй **Client ID** и **Client Secret** (кнопка Reset Secret). В **Redirects** добавь:
   ```
   https://127.0.0.1
   https://ТВОЙ-ПРОЕКТ.vercel.app/api/auth/callback/discord
   ```
3. **Activities → URL Mappings** (раздел может называться Embedded App). Добавь три строки:

   | PREFIX | TARGET |
   |---|---|
   | `/` | `ТВОЙ-ПРОЕКТ.vercel.app` |
   | `/dcdn` | `cdn.discordapp.com` |
   | `/gcdn` | `lh3.googleusercontent.com` |

   Адреса пиши без `https://`. Вторая и третья строки нужны для иконок серверов.
4. **Activities → Settings**: включи **Enable Activities**. В Supported Platforms отметь Web, а также iOS и Android, если хочешь играть с телефона.
5. **Installation**: включи Guild Install. По ссылке оттуда добавь приложение на свой сервер.

### 5. (Необязательно) Вход через Google на сайте
console.cloud.google.com → создай проект → **OAuth consent screen** (External) → **Credentials → OAuth client ID** (Web application).
В Redirect URI укажи `https://ТВОЙ-ПРОЕКТ.vercel.app/api/auth/callback/google`.
Пока приложение в режиме Testing, входить могут только почты из списка Test users.

### 6. Переменные на Vercel
**Settings → Environment Variables**. Полный список с пояснениями лежит в `.env.example`. Минимум:

| Имя | Значение |
|---|---|
| `AUTH_SECRET` | длинная случайная строка |
| `GAME_SALT` | случайная строка, **потом не меняй** |
| `AUTH_DISCORD_ID` и `NEXT_PUBLIC_DISCORD_CLIENT_ID` | Client ID из Discord |
| `AUTH_DISCORD_SECRET` | Client Secret из Discord |
| `ADMIN_SECRET` | длинная случайная строка для выдачи промокодов |
| `NEXT_PUBLIC_SITE_URL` | `https://ТВОЙ-ПРОЕКТ.vercel.app` |
| `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET` | если нужен вход через Google |

Затем **Deployments → … → Redeploy**. Переменные `NEXT_PUBLIC_*` подхватываются только при новой сборке.

### 7. Играйте
- **Сайт:** открой адрес проекта и войди.
- **Discord:** зайди в голосовой канал → значок ракеты (Activities) → выбери Dotadle. Пока приложение не прошло проверку Discord, запускать его могут участники серверов, куда оно добавлено.

> ⚠️ Discord в России работает только через VPN. Если у кого-то из друзей Activity не грузится, сначала проверь, открывается ли у него сайт напрямую.

## Как выдавать плюшки за донаты

1. Укажи ссылку на донат в `NEXT_PUBLIC_DONATE_URL`, например на страницу Boosty.
2. Когда человек задонатил, создай для него код (подставь свои адрес и `ADMIN_SECRET`):
   ```bash
   # Саппортер на 30 дней
   curl -X POST https://ТВОЙ-ПРОЕКТ.vercel.app/api/admin \
     -H "x-admin-secret: ТВОЙ_ADMIN_SECRET" -H "Content-Type: application/json" \
     -d '{"action":"createCode","type":"supporter","days":30}'

   # Лига+ на 30 дней (для сервера или лиги)
   curl -X POST https://ТВОЙ-ПРОЕКТ.vercel.app/api/admin \
     -H "x-admin-secret: ТВОЙ_ADMIN_SECRET" -H "Content-Type: application/json" \
     -d '{"action":"createCode","type":"league","days":30}'
   ```
   В ответе придёт код вида `SUP-ABCD1234` или `LIGA-ABCD1234`. Отправь его человеку.
   На Boosty можно прикрепить код к посту, доступному только подписчикам.
3. Человек вводит код в **Профиль → Поддержка → Активировать код**. Код Лиги+ активируется для выбранной лиги, и активировавший становится её админом.

Другие команды админки: `listCodes` (все коды); `grantSupporter` с полями `uid` и `days`; `grantLeague` с полями `lid` и `days`.
Можно задать свой код: `"code":"FRIENDS2026"`. Многоразовый код: `"maxUses":50`.

Когда решишь включить платные функции, поставь `PAYWALL=on` и сделай Redeploy.

## Сообщения в Discord-канал и итоги дня
Админ сервера открывает **Профиль → Лиги → 💬 Присылать результаты в канал** и вставляет ссылку вебхука.
Её можно взять в Discord: настройки канала → Интеграция → Вебхуки → Новый вебхук → Копировать URL вебхука.
После этого в канал приходят:
- результат каждого игрока лиги в классике и портрете (сетка 🟩🟥, ответ не раскрывается, серия 🔥);
- результаты гонок, запущенных на этом сервере;
- каждую ночь в 00:10 по Москве итоги дня: кто был загадан, кто как угадал, лидеры по сериям, топ сезона.

Чтобы ночные итоги работали, добавь на Vercel переменную `CRON_SECRET` (любая длинная строка, тип Secret).
Расписание уже лежит в `vercel.json`, Vercel подхватит его сам.

**Серия 🔥:** сколько дней подряд игрок угадывает героя дня (засчитывается классика или портрет).

## Турниры и спонсоры
Админ лиги (на Discord-сервере это владелец или люди с правом «Управлять сервером») открывает **Профиль → Лиги → + Новый турнир**.
Там указываются название, даты, режимы и, по желанию, спонсор: название, ссылка и приз. Очки за выбранные режимы в эти дни идут в таблицу турнира.
Таблица турнира с блоком спонсора видна в **Рейтинг → лига → Турниры**.

## Локальный запуск
```bash
npm install
cp .env.example .env.local      # заполни, для теста добавь DEV_LOGIN=1 и NEXT_PUBLIC_DEV_LOGIN=1
npm run dev                     # http://localhost:3000
```
Без Redis данные хранятся в памяти и пропадают при перезапуске, сайт об этом предупредит.
`DEV_LOGIN` включает тестовый вход по имени. **Никогда не включай его на Vercel.**

Чтобы проверить Activity локально, запусти туннель `cloudflared tunnel --url http://localhost:3000` и временно укажи его адрес в URL Mapping `/`.

## Что где менять
- Очки и время: `lib/game.ts`.
- Уровни чёткости портрета и подсказки: `lib/portrait.ts`.
- Длительность раундов гонки: `lib/race.ts`.
- Цвета ников и темы: `lib/users.ts` и `app/globals.css`.
- Русские названия героев для поиска: поле `ru` в `lib/heroes.json`.
- Когда выйдет новый герой, добавь его в `lib/heroes.json` (с полями `gender` и `race`) и запусти `python3 scripts/make_assets.py ПАПКА_С_ПОРТРЕТАМИ`: скрипт сделает портреты в `public/heroes/p` и сетки для режима «Портрет».
